ИНСТРУКЦИЯ ПО НАСТРОЙКЕ И ЗАГРУЗКЕ ПРОЕКТА (GitLab)

Шаг 1: Подготовка файлов (для того, кто передает)
1. Удали папку 'target' (это временные файлы компиляции, они не нужны).
2. Удали папку '.idea' (это настройки твоей среды разработки, у подруги они создадутся сами).
3. Запакуй остальные файлы в ZIP-архив (src, pom.xml, GEMINI.md, csv файлы).

Шаг 2: Открытие проекта (для подруги)
1. Распакуй архив в новую папку на компьютере.
2. Открой IntelliJ IDEA.
3. Нажми "Open" (или "File -> Open").
4. ВЫБЕРИ ФАЙЛ 'pom.xml' в папке проекта.
5. Нажми "Open as Project".
6. Если появится окно "Trust Project", нажми "Trust Project".
7. В правом нижнем углу появится уведомление "Maven projects need to be imported" — нажми "Load Maven Changes" (или значок "обновить" в панели Maven справа).
8. Дождись, пока IntelliJ скачает Selenium и JUnit (индикатор внизу).

Шаг 3: Проверка тестов
1. Перейди в src/test/java/net/phptravels/tests.
2. Нажми правой кнопкой мыши на 'FlightsTest' -> 'Run FlightsTest'.
3. Если браузер открылся и тесты пошли — всё настроено правильно.

Шаг 4: Загрузка в GitLab (с коммитами)
Чтобы не делать один огромный коммит, лучше сделать 2-3 логических шага:

1. Настройка Git:
   - В терминале IntelliJ IDEA (внизу вкладка Terminal) напиши:
     git init
     git remote add origin [ССЫЛКА_НА_ЕЕ_РЕПОЗИТОРИЙ_GITLAB]

2. Первый коммит (Основа):
   - Выбери файлы: pom.xml, BasePage.java, BaseTest.java.
   - Сделай коммит: "Setup project structure and base classes"

3. Второй коммит (Логика страниц):
   - Выбери все остальные файлы в папке 'pages'.
   - Сделай коммит: "Implement Page Object models for Flights, Visa and Login"

4. Третий коммит (Тесты и данные):
   - Выбери папку 'tests' и папку 'resources' с CSV файлами.
   - Сделай коммит: "Add E2E tests and data-driven testing scenarios"

5. Пуш в GitLab:
   - git push -u origin main (или master)

ВАЖНО:
- Если тесты не видят Chrome, проверь, что он установлен в системе.
- Все библиотеки подтянутся сами благодаря файлу pom.xml.
- Не нужно вручную создавать папки, IntelliJ всё увидит после открытия pom.xml.
